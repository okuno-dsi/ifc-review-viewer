# Main IFC Folder

Place approved distributable main IFC files in this folder for local review packages.

Do not commit project IFC files to GitHub unless the project owner has explicitly approved public redistribution. This repository ignores `*.ifc` files by default.

Example:

```text
DISTRIBUTABLE_PACKAGE/IFC/MainModel.ifc
```

Open the main IFC first in `IFCReviewViewer_Standalone.html`.
